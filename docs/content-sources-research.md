# 内置内容数据源调研（真题 / 教程例题习题）

调研日期：2026-09-27（英文源翻译路线于同日补充核实）。结论供"初版内置数据"选型参考。

## TL;DR

1. **考研真题（题干）可以内置**：行业惯例全网转载，且有判例支持"试题题干属公有领域"；但要**自己重排（LaTeX）+ 自写解析**，不能搬运任何机构的解析文字。风险低-中，可再通过"题库与应用分离分发"进一步隔离。
2. **内容红线（项目决定）**：国内版权受限教材与教辅（同济《高等数学》《线性代数》、复习全书、660/1000/1800 题等）**只作参考，内容一律不使用**——参考指对齐考点体系、校验难度定位、了解题型风格；其例题、习题、解析文字不录入、不改编、不进任何内置/分发的题库。题目内容来自三条干净路线：真题题干自录、英文开放教材翻译（版权方联系中）、自编/AI 生成题。
2. **教程例题/习题走英文开放教材翻译路线，可行且许可已逐本核实**：绿色许可（可翻译、可商用、条件仅为署名/相同方式共享）有 **Active Calculus（CC BY-SA）、Corral《Vector Calculus》（GFDL）、Crowell（CC BY-SA/GFDL）** 及公版书 **Granville 1904**；OpenStax、APEX、Guichard、MIT OCW 均为 **NC（非商用）**，免费开源 app 可用但锁死商业化。详见第四节。
3. **市面上没有现成的结构化考研数学开放数据集**：HuggingFace 上考研数学数据集基本空白（仅一个 45 下载量的 QA 小集）；NuminaMath 等大数据集是竞赛/K12 风格且中文化不符。**空白即机会**——mathlink 可以做第一个开源的结构化考研数学题库。
4. App 侧需要先补的数据模型缺口：题目文本字段（当前只有图片）、来源元数据、`origin: builtin` 标记、Rust 侧批量导入命令。

## 一、版权风险分析（国内判例）

| 内容 | 风险 | 依据 |
|---|---|---|
| 真题题干（自录重排） | 🟢 低-中 | 深圳中院再审（菁优诉豆丁，2020）：**"高考数学试题属于公有领域的内容"**，题干不受保护；但法律无明文（新华网《公共试题能享有著作权吗》：属法律空白，医考中心诉科学出版社等案中考试机构亦有胜诉记录） |
| 试卷整体原样复制 | 🟡 中 | 单套试卷的**选编结构**可能构成汇编作品（光明日报分析：需同时使用内容+编排才侵权）→ 按**考点打散重组**反而更安全，恰好是本 app 的形态 |
| 他人解析（书籍/网站/MathMaster） | 🔴 高 | 深圳中院同案：解析中的解题思路分析、点评**有独创性、构成作品**。ETS 诉新东方（2003，赔 1000 万）同理 |
| 教材/教辅习题（同济、660 题、1000 题等） | 🔴 高 | 明确受著作权保护的商业出版物 |
| 个人截图/摘录自用 | 🟢 合理使用 | 著作权法第 24 条：为个人学习、研究使用已发表作品属合理使用。app 现有"自录题库"工作流没问题，与"内置分发"是两回事 |
| 自编题 / AI 生成题 | 🟢 干净 | 无第三方权利，可任意许可 |
| **英文 OER 翻译** | 🟢 取决于原书许可 | 翻译是演绎作品，须原书许可允许"改编/演绎"（CC 系都允许；ND 条款才禁止）。逐本核实见第四节 |

操作守则：内置真题 = 题干 LaTeX 重排 + 客观答案（选择题字母/填空数值本身不受保护）+ **自写**简解/提示；标注"20XX 年数学一 第 N 题"；不复制任何机构解析的表述、不整卷照搬扫描件。**国内版权受限教材只参考不使用**（见 TL;DR 红线）：真题仓库里的商业书扫描 PDF 仅用于核对题干文字，不复制其版面、图片与解析。

### 4.3 翻译与制作管线建议

1. **选源组合（v1 推荐）**：Active Calculus（BY-SA，例题+习题主体）+ Corral（GFDL，第 4–6 章主力）+ Granville（公版，基础计算题补充）。NC 组（OpenStax/APEX）视需要后补——一旦收录，题库包须标注非商用。
2. **术语表先行**：先建"英文术语 → 考研规范中文"对照表再批量翻译。已知坑：**concave up/down 与国内"凹/凸"定义方向相反**（国内同济体系 concave up = 凹）；implicit differentiation 隐函数求导、antiderivative 原函数/不定积分、solid of revolution 旋转体等需统一。
3. **抽取**：Active Calculus 用 PreTeXt XML 直接抽 `exercise` 节点；Corral/APEX 用 LaTeX 源按 `\begin{exercise}` 等环境正则抽取——公式原样保留，只翻 prose。
4. **翻译**：LLM 初翻（公式零改动）→ 人工校对（术语一致性 + 数字/符号比对）。单题题干短，估 3–6 分钟/题（含打标）。
5. **许可合规**：按来源**分组打包、沿用原许可**——BY-SA 组整体 CC BY-SA 4.0，GFDL 组保持 GFDL，公版组随意；每题带 `source: {book, section, license}` 元数据，包内附署名与许可全文。BY-SA 与 GFDL 不互通，别混在一个许可证下。
6. **规模**：v1 目标 8 章 × 30–50 题 ≈ 300 题，约 25–40 小时人工（LLM 辅助后）；与真题库（近 10 年数一 ≈125 题）并行推进。

### 4.4 "自用"与"分发"的法律边界（项目定位：学习目的）

- **个人自用（合法，无需考虑任何教材版权）**：《著作权法》第 24 条第（一）项"为个人学习、研究或者欣赏，使用他人已经发表的作品"是宽泛的合理使用，翻译任何英文教材（含全保留版权的商业教材）的习题供自己练习均在其内。**前提是成果只留在本机**——不进公开仓库、不进发行包、不通过网络传给他人。
- **分发（超出合理使用）**：翻译结果一旦随 app 内置分发（EXE/APK、公开 GitHub 仓库、可下载题库包），即属复制 + 信息网络传播，第 24 条不再覆盖；外国作品经伯尔尼公约在中国受同等保护，CC 许可在国内司法实践中亦有效。另外注意：GitHub 公开仓库适用美国法与 DMCA，英文教材出版商有投诉先例，与开发者所在国无关。
- **执行口径**：自用题库（任何来源）只存本机，通过"导入题库包"功能进入 app；公开渠道分发的题库包仅使用第四节绿色源 + 真题（自录题干）。App 本体保持零内置内容，天然隔离。

## 五、与现有 App 的对接缺口

现状（见 `src/types.ts`、`src-tauri/src/lib.rs`）：

1. `Problem` 只有 `questionImages/answerImages`，**无文本字段** → 需加 `questionText`/`answerText`（KaTeX，复用 `FormulaText` 组件）；
2. 无来源元数据 → 加 `source: { kind: "exam" | "example" | "custom", year?, paper?, book?, section?, license? }`（自由文本先塞 notes 也行，但结构化后才能按年份/来源筛选）；
3. 无 `origin: "builtin" | "user"` → 内置题只读 + 升级合并，仿 `seedDefinitions` 的 merge-by-id 先例（`src/definitions.ts`）；
4. Rust 侧只有单条 `create_problem` → 需要批量 seed/import 命令（否则 Tauri 模式下前端 seed 只写 localStorage）；
5. 分类格式可对齐现成的 `data/problem-classification.schema.json`，但其 `methods.recommended_ids/alternative_ids` 与实现的扁平 `methodIds` 不一致，需先统一；
6. taxonomy 目前单科（高数）→ v1 只收高数题正好匹配；扩线代/概率时再动 taxonomy 结构。

## 六、推荐路线

- **v1 真题包**：`data/bank-calculus-v1.json`（近 10 年数一高数 ≈125 题：题干 LaTeX 重排 + 客观答案 + 自写一句话提示 + 全量打标），构建期静态导入，仿 taxonomy 的做法。
- **v1 例题包（英文源翻译）**：Active Calculus + Corral + Granville，按 4.3 管线制作 ≈300 题，`source.kind: "example"`，按来源分组沿用许可。
- **分发隔离**：题库 JSON 放**独立仓库 / 独立下载包**，app 本体保持零内置内容、提供"导入题库包"功能——既隔离版权风险，也顺应"应用与数据分离"的现有架构；用户个人仍可自行截图导入自己持有的资料（个人合理使用，属用户行为，与内置/分发内容无关）。
- **补缺口**：ODE 深度内容找专门 ODE 开放教材；证明题风格内容靠真题库和自编题补。
- **同步开源**：结构化题库本身可开源共建（行业先例多），README 注明各分组许可；真题组注明"题干为公开试题重排，解析为本项目原创；如权利方提出异议将即时下架相应条目"。

## 七、全科覆盖（数一/二/三）补充调研

范围扩大到数学一/二/三全科后的结构与素材。App 侧改造见独立交付物 `docs/upgrade-prompt-full-syllabus.md`。

### 7.1 大纲结构（2021 年起施行，2026 年沿用，已对照官方大纲原文核实）

| 科目 | 章节 | 卷种差异 |
|---|---|---|
| 高等数学 | 1 函数极限连续 / 2 一元微分 / 3 一元积分 / 4 向量代数与空间解析几何 / 5 多元微分 / 6 多元积分（重积分；数一含三重、曲线、曲面）/ 7 无穷级数 / 8 常微分方程 | 数一最全（含空间几何、三重/曲线/曲面积分、傅里叶、欧拉方程、方向导数梯度）；数二无级数/空间几何/三重及曲线曲面积分，特色是物理应用与曲率；数三特色是差分方程、经济应用（边际弹性）、无界区域反常二重积分，无傅里叶/曲率/物理应用 |
| 线性代数 | 行列式 / 矩阵 / 向量 / 线性方程组 / 特征值与特征向量 / 二次型 | 三卷 6 章一致（数二 2021 起也含二次型）；数一独有：向量空间、基变换与坐标变换、过渡矩阵、解空间 |
| 概率论与数理统计 | 随机事件和概率 / 随机变量及其分布 / 多维随机变量 / 数字特征 / 大数定律与中心极限定理 / 数理统计基本概念 / 参数估计 / 假设检验 | 数一 8 章全考（参数估计含区间估计）；数三不考假设检验及区间估计（参数估计仅点估计）；数二整科不考 |

试卷结构（三卷统一）：10 单选×5 分 + 6 填空×5 分 + 6 解答共 70 分 = 22 题 150 分。占比：数一 高数60/线代20/概率20；数二 高数80/线代20；数三 微积分60/线代20/概率20。

现 taxonomy 缺口：无"向量代数和空间解析几何"章（现有 8 章把多元积分拆成了"多元函数积分学"+"曲线与曲面积分"两章，id 保持不动即可）；线代、概率两科整体缺失；全部节点缺 `applicable_exams` 打标。

### 7.3 全科素材结论与缺口

- **绿色组合可覆盖大部分**：高数（Active Calculus + Corral + Granville）、线代（Hefferon）、概率论（Grinstead-Snell）、数理统计（OpenIntro，需挑选）。
- **全科硬缺口（英文源无对应，靠真题库 + 自编题补）**：二次型（Hefferon/Beezer 均无专章）、差分方程（数三，英文初等教材基本不讲）、经济应用（边际/弹性）、物理应用（数二风格）、中值定理/不等式证明题、傅里叶级数习题（Corral/OpenStax V2 有但少）、区间估计与假设检验的考研风格题（OpenIntro 风格不符）。
- **真题侧无需新增工作**：真题包本身覆盖三科（数一/三卷内含线代概率题，数二含线代题），只需按第七章大纲打标即可；近 10 年三卷全科目题量约 220×3=660 道（高数约 400 + 线代约 130 + 概率约 130，未去重）。
